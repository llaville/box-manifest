
## 4.5.0 - 2026-10-04

### Changed

- drop dependency support to `cyclonedx/cyclonedx-library` version 3.0 and upgrade to major version 4.0
- add the new Composer Manifest format into the BOX (PHAR distribution)
- upgrade custom autoloader (`autoload.php`) to be PHAR distribution compatible

QA pipeline with CaptainHook :

- upgrade all CaptainHook config files to be compatible with `bartlett/captainhook-bin-plugin` 1.1.0
- re-enable PHP-CS-Fixer hook
- re-enable Mago hook

QA pipeline with MegaLinter :

- fixed PHPStan version compatibility reporting : read more at <https://github.com/llaville/box-manifest/issues/19>

### Fixed

- Coding Standard in all source code following PHP-CS-Fixer rules defined by [configuration](https://github.com/llaville/box-manifest/commit/e1da200b9e2dc78782f872bea6e14687d99c05b6)
- Help of the `make` command, show missing output formats (Composer Tree), available since version 4.4.0
- Build resources with always a fresh metadata file (`.box.manifests.bin`)
- Support to `check-requirements` BOX configuration
